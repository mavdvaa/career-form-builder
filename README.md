# CareerForm

Простой сервис форм отклика на чистом Node.js. Сторонние библиотеки и отдельная база данных не нужны: формы и ответы хранятся в `data/store.json`.

## Запуск

Требуется Node.js 20 или новее:

```sh
npm install
npm start
```

Админка: [http://localhost:3000/admin](http://localhost:3000/admin). Чтобы использовать другой порт, задайте переменную окружения `PORT`.

## Использование

1. Создайте форму, задайте название и добавьте вопросы.
2. Нажмите «Опубликовать» и передайте студентам ссылку.
3. Просматривайте отклики в админке.
