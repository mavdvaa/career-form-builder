# CareerForm

Простой сервис создания форм отклика на Node.js. Структура проекта похожа на `handler` и `worker`: точка входа, обработчик запросов, функции, работа с данными и тесты.

## Запуск

Нужен Node.js 20 или новее:

```sh
npm install
npm start
```

Админка доступна по адресу [http://localhost:3000/admin](http://localhost:3000/admin). Порт задаётся переменной `PORT`.

## Как пользоваться

Создайте форму в админке, добавьте вопросы и нажмите «Опубликовать». Ссылку можно отправить студентам; их ответы появятся в разделе откликов.

Формы и ответы хранятся в локальном JSON-файле `data/store.json`. Отдельная база данных не используется; сторонние библиотеки и API-ключи не нужны.
